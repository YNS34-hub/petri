# 推友斗菌场

20 秒抢食竞技。输入网名生成小生物，吃蓝泡、躲红菌、冲刺连击；打完把真实操作残影发给朋友，让对方来追你的分数。来自 [AMZ / @AmzTjh34230](https://x.com/AmzTjh34230)。

[进入竞技场](https://yns34-hub.github.io/petri/)

![推友培养皿](dist/cover.png)

六类选手拥有不同形体、触须和表情。鼠标或手指控制，WASD / 方向键也可移动；空格或按钮冲刺。连续吃泡泡，连击最高五倍，撞到红菌扣 15 分。每天采用北京时间对应的场地种子；残影挑战使用朋友分享的种子。双方不必同时在线。

## 运行

需要 Node.js 20 或以上版本。无需依赖安装和编译。

```sh
npm start
```

打开 `http://127.0.0.1:4177`。`npm test` 执行 Node 内置测试。

## 文件

- `dist/index.html`、`style.css`：网页与手机布局。
- `dist/genetics.js`：网名校验、稳定生成、双人结果、分享链接。
- `dist/battle.js`：北京时间每日场地、真实轨迹压缩、挑战链接校验与残影采样。
- `dist/world.js`：原生 Canvas 渲染、生物物理、玻璃培养皿、图片导出。
- `dist/app.js`：选手、倒计时、开战、结算、残影邀战与海报下载。
- `dist/press.html`、`press.js`：用同一渲染器生成发布封面、AMZ 物种证件和双人示例。
- `scripts/serve.mjs`：只绑定本机回环地址的静态预览服务器。
- `tests/`：生成逻辑、输入边界、轨迹往返、残影插值与链接安全测试。

## 数据与分享

不读取 X 账号，不请求登录，也不调用 AI 或上传输入。完整挑战链接携带选手网名、心情、种子，以及每 200 毫秒记录的一份位置与分数快照，共 101 帧。朋友打开能看到真实一局的残影。分享到 X 只打开预填编辑器，由使用者自行决定是否发布。

图片在浏览器本地导出，战绩和选手证件为 1400×1700 PNG；社交封面为 1200×675 PNG。无假排行榜和真人在线匹配。数据可由用户自行修改，适用于趣味挑战，不提供认证排名。

动态画面约 30 FPS，像素比限制为 1.5。页面不可见时停止物理和绘制；减少动态效果偏好下默认暂停，可手动继续。

## 更新发布

静态文件从 `gh-pages` 分支根目录发布。

```sh
git push origin main
git subtree push --prefix dist origin gh-pages
```

修改托管域名时，同步修改分享元数据、海报底部网址、素材页网址和本文件链接。
